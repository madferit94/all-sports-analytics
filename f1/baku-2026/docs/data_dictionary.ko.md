# 데이터 사전

[English](data_dictionary.md)

| 표·컬럼 | 한 행의 의미·정의 | 주의점 |
|---|---|---|
| `laps` / `analysis_lap_base` | 세션·드라이버·랩 하나. 랩타임 단위는 초 | 전체 선수의 랩타임 7개가 결측입니다. |
| `drivers` | 세션·드라이버 하나 | 차량 번호는 해당 세션 기준으로 사용합니다. |
| `session_result` / `top10_drivers` | 최종 순위와 공식 시간 차이 | 최종 Top 10은 비완주자를 제외하므로 신뢰성 분석 표본이 아닙니다. |
| `stints` | 드라이버의 타이어 사용 구간. 시작·끝 랩 포함 | 시작 사용량을 확인하세요. 새 구간이 새 타이어를 뜻하지 않습니다. |
| `tyre_age_start_lap_est` | 구간 시작 사용량 + 현재 랩 − 구간 시작 랩 | 추정 사용량. 미매칭·다중 매칭은 그대로 남깁니다. |
| `pit` / `has_pit_lane_record` | 피트레인 활동 / 해당 랩 기록 존재 여부 | 피트레인 통과만으로 타이어 교체를 확정할 수 없습니다. |
| `race_control_events` | 경기 전후까지 포함한 운영 공지 하나 | 공지 랩 번호를 특정 선수의 영향받은 랩과 동일시하지 않습니다. |
| `race_control_during_race` | 세션 시작~종료 구간 공지 | 공지가 없다는 것이 모든 사고의 부재를 증명하지 않습니다. |
| `safety_car_boundary_candidates` | 투입·복귀 예고·다음 선두 랩 시작 | 실제 재출발 경계는 검토가 필요합니다. |
| `intervals` | 시각별 시간 차이. 숫자는 초 단위 | 결측·랩 차이 문자열을 0으로 바꾸지 않습니다. |
| `position` | 시각별 순위 | 출발 그리드 결과가 아닙니다. |
| `location` | 시각별 임의 좌표계 x/y/z 위치 표본 | 대략적인 이동이며 정밀 주행 라인·시간 차이가 아닙니다. |
| `weather` | 세션 날씨 표본 | 맥락 자료이며 자동으로 인과적 통제가 되는 것은 아닙니다. |
| `lap_start_utc` / `lap_end_est_utc` | 시작 시각 / 시작+랩타임 | 시간 구간 필터 전 다음 랩 시작과 비교해야 합니다. |
| `pace_eligible` | 최종 비교 랩 여부. 결측 가능 | 시간 검토 중이어서 현재 비워둡니다. |
| `race_control_review` | 랩의 검토 상태 | 대기 상태는 비교 적격을 뜻하지 않습니다. |

원본 파일명에 요청 조건을 남기고 CSV는 UTF-8 BOM으로 저장합니다. 원본 목록에는 URL·행 수·SHA-256·확인된 수집 시각·기존 자료 재사용 여부가 있습니다. 최초 수집 시각이 확인되지 않으면 null을 유지합니다.
