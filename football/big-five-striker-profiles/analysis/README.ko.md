## 분석 질문과 결과

기록상 중앙 공격수 후보는 비페널티 슈팅 빈도, 슈팅당 기회 품질, 실제 득점 전환에서 어떻게 다른가요? 2026년 10월 3일 저장한 Understat 2025/26 자료의 선수 181명을 기술적으로 비교했습니다. [영어 가로형 PDF 13장](../presentation/Beyond_Goals_EN_Landscape_verified.pdf)과 [편집용 PPT](../presentation/Beyond_Goals_EN_Landscape_verified.pptx)에서 시각적으로 설명합니다.

## 데이터와 지표

`data/input`의 CSV 4개는 기존 `../data/processed`에서 복사했습니다. 파일 내용은 같고 해시는 `data/input_manifest.json`에 기록했습니다. 기준은 기록상 중앙 공격수 후보·900분 이상·비페널티 슈팅 1회 이상·품질 검증 통과입니다. 다른 포지션으로 뛴 기록도 선수의 시즌 지표에 포함합니다.

비페널티(NP)는 페널티와 자책골 이벤트를 제외한다는 뜻입니다. 다른 세트피스는 포함합니다.

- 슈팅/90 = NP 슈팅 ÷ 출전시간 × 90.
- xG/슈팅 = NP 슈팅의 xG 합계 ÷ NP 슈팅.
- xG/90 = NP 슈팅의 xG 합계 ÷ 출전시간 × 90.
- 실제 전환율 = NP 득점 ÷ NP 슈팅 × 100. 기대 전환율 = xG/슈팅 × 100.
- 초과 득점 = NP 득점 − NP 슈팅 xG 합계.

xG는 모델이 추정한 슈팅의 득점 가능성입니다. 리그 합산 전환율은 득점 합계/슈팅 합계이며 선수 비율의 단순 평균이 아닙니다. 리그 백분위는 선정된 후보 안에서의 상대 위치입니다.

## 서로 다른 세 가지 선정 기준

| 대상 | 선정 방법 | 의미 |
|---|---|---|
| 유형별 사례 4명 | 전체 181명의 두 지표 중앙값으로 네 유형 구분. NP 슈팅 50회 이상 중 유형 중앙값에 가장 가까운 선수. 거리는 전체 대상 표준편차로 보정 | 서로 다른 유형 설명 |
| 두 지표 동시 상위 7명 | NP 슈팅 50회 이상, 두 지표 모두 전체 대상의 상위 25% 기준 이상 | 빈도와 기회 품질이 함께 높은 프로필 |
| 리그별 대표 5명 | NP 슈팅 50회 이상, 리그별 xG/90 최고. 동률은 출전시간 내림차순 → 숫자 선수 ID 오름차순 | 리그 안의 기대 슈팅 생산량 비교 |

네 사례는 에키티케(많이·높음), 부디미르(많이·낮음), 호일룬(적게·높음), 펠레그리노(적게·낮음)입니다. 최고 선수 4명이 아니라 유형의 중심에 가까운 설명용 사례입니다. 리그 대표는 홀란드·레반도프스키·케인·크르스토비치·오바메양입니다.

리그별 최다 득점자는 전체 선수 요약 2,775행에서 페널티 포함 총득점으로 따로 선정했습니다: 홀란드·음바페·케인·라우타로·르폴입니다. 리그 대표와 목적이 다릅니다. 어떤 목록도 종합 능력 순위가 아닙니다.

## 결과와 검증

실행마다 PNG/SVG 차트 8개, 지표·리그·사례·슈팅 구성·경기 분포·선정 근거 CSV와 JSON을 저장합니다. 모든 출전을 기준으로 슈팅을 연결하므로 무슈팅 경기도 남습니다. “60분 이상 무슈팅”은 한 경기에서 60분 이상 출전하고 NP 슈팅이 0회라는 뜻이며 연속 60분 구간을 추적한 지표가 아닙니다. 경기 산점도는 모든 출전을 표시합니다.

[검증 폴더](../verification/README.ko.md)에는 77개 교차 검증, PPT 차트 16개와 포함 워크북 숫자 2,381개, PDF 13장 이미지 대조 근거가 있습니다. 원본 출전 중복의 영향을 받은 후보 12행은 제외했습니다. 전체 원본 캐시는 로컬에 보존합니다.

## 한계와 다음 단계

저장한 한 시즌 자료입니다. 리그 수준·팀·상대·경기 상황 보정, 수비 분석, 공식 경기 기록과의 독립 대조, xG 모델 정확성 검증은 하지 않았습니다. 초과 득점은 지속적인 마무리 능력을 증명하지 않습니다. 슈팅 좌표는 0~1 정규화 값이며 실제 미터나 오프더볼 움직임이 아닙니다. Microsoft PowerPoint 앱에서 직접 열어 보지는 않았으므로 게시에는 검증된 PDF를 사용하세요. 다음 단계는 외부 경기 기록 대조와 여러 시즌·맥락 비교입니다.
