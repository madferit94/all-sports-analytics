# 발표 자료와 검증

[English](README.md) | [한국어](README.ko.md)

LinkedIn에는 [영어 가로형 PDF 13장](Beyond_Goals_EN_Landscape_verified.pdf)을 사용하고, 수정에는 [편집용 PPT](Beyond_Goals_EN_Landscape_verified.pptx)를 사용하세요. 개별 장 이미지는 `slides/`에 있습니다. 여기에는 최종 검증본만 게시했습니다.

분석 질문·대상 → 리그별 프로필 → 리그 대표 → 네 사례의 선정 이유 → 전환율 → 리그별 최다 득점자 → 슈팅 위치·신체 부위 → 경기 변동 → 한계 순서입니다. PDF 13장의 이미지와 최종 PPT 렌더링이 일치합니다. 차트·수치 캐시·포함 워크북은 대조했지만 Microsoft PowerPoint 앱에서 직접 실행하지는 않았습니다.

리그 대표, 네 사례, 최다 득점자는 서로 다른 질문에 대한 선정입니다. [분석 안내](../analysis/README.ko.md)에서 기준을 확인하세요. 출처·계산식·한계는 PPT 발표자 노트와 [출처 메모](source_notes.md)에 남겨두었습니다. [영어 LinkedIn 글](LinkedIn_caption_EN.txt)은 직접 게시할 수 있는 초안이며 이번 작업에서 글을 게시하지는 않았습니다.
