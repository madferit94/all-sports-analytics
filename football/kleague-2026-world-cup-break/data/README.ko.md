출처: [K리그 공식 데이터 포털](https://data.kleague.com/). 아래 저장 파일을 `data/raw/`(또는 `KLEAGUE_DATA_DIR`로 지정한 폴더)에 넣어 주세요.

| 파일 | 예상 행 수 | 용도 |
|---|---:|---|
| `kleague1_2026_round01-30_results_weather.csv` | 180 | 배정 라운드, 실제 날짜, 팀, 최종 스코어, 원본 URL |
| `kleague1_2026_round01-30_teamstats_raw.csv` | 360 | 제공처의 팀-경기 기록. 경기당 두 행 |
| `official_score_reconciliation.csv` | 360 | 공식 최종 스코어와의 저장된 대조 |
| `official_totals_reconciliation.csv` | 564 | 알려진 `GOAL_CNT` 불일치를 포함한 팀 합계 점검 저장본 |

`input_manifest.json`에 예상 파일 해시, 행 수, 열이 기록되어 있습니다. 출처를 추적할 수 있도록 파일 이름과 원본 항목 이름은 그대로 둡니다. 한글 팀 식별자와 원본 득점 항목 `home_득점` / `away_득점`은 v1에서 영어 분석용 이름으로 바꾸며, 원본 매핑 코드에 한글이 있는 것은 의도한 것입니다.

원본 파일은 Git에서 제외했습니다. 공개 재배포 허락을 확인하지 못했기 때문입니다. 분석 스크립트에는 로그인 정보, 세션 쿠키, 개인 컴퓨터 경로가 필요하지 않습니다. 로그인 정보를 공개하지 말고, 공개 웹사이트에 접근할 수 있다고 해서 데이터 사용 허락이 있다고 가정하지 마세요.

이 원본 스냅샷에는 22라운드로 배정되어 2026-09-27에 열린 강원–인천 경기가 들어 있습니다. 그 전의 179경기 파일은 **바꿔 쓸 수 없는** 입력입니다. 범위가 달라지면 코드가 일부러 멈추도록 되어 있습니다. 시즌 종료 분석에는 검사를 끄는 것이 아니라 새 범위와 검증 규칙이 필요합니다.

이 파이프라인은 저장된 파일만 읽습니다. 수집기가 들어 있지 않고, 대조 파일을 자동으로 새로 받지 않으며, 원본 수집을 처음부터 재현한다고 주장하지 않습니다. 스냅샷 점검일: 2026-09-30.
