# 과거 F1 탐색 분석 대시보드

[English](README.md) · [한국어](README.ko.md)

시즌별 DNF, 출발 대비 완주 순위 변화, 선수·팀 총점을 보여주는 기존 Streamlit 대시보드입니다. 저장 CSV는 **1950–2025년**이며 앱 기본 범위는 2000년 이후입니다. 2016년 시작을 강제하지 않습니다.

**상태: 기존 대시보드 기반 유지, 지표 수정 필요.** [운영 사이트 링크](https://f1-modern-era-eda.streamlit.app/)는 유지하지만 이번 검토에서 운영 상태는 확인하지 않았습니다.

[앱 코드](app.py) · [유지·수정 검토](../f1/baku-2026/docs/existing_f1_review.ko.md) · [새 바쿠 프로젝트](../f1/baku-2026/README.ko.md)

## 포트폴리오에 사용하기 전 수정

입력 자료가 `+N Lap(s)`라는 뒤처진 완주 상태를 DNF로 처리하므로 신뢰성 지표를 다시 만들어야 합니다. 현재 경기 수는 GP 이름 종류 수이므로 시즌+라운드의 경기 수로 바꿔야 합니다. 순위 변화는 결측 완주를 제외한 표본임을 밝히고, 총점은 참가 횟수 차이가 있어 통제된 선수 실력으로 해석하지 않습니다.

앱·CSV·과거 예측 노트북은 보존했습니다. 바쿠는 경기 중 별도 질문이며 이 대시보드를 대체하지 않습니다.
