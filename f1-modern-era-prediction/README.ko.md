# 과거 F1 경기 전 예측 실험 (2016–2025)

[English](README.md) · [한국어](README.ko.md)

과거 결과 표로 선수·팀의 최근 성적 변수를 만들고 우승·Top 10 분류를 탐색한 프로젝트입니다. **경기 전 예측의 실험용 기준 모델**이며 검증된 운영 전략 시스템은 아닙니다.

**상태: 학습 기록으로 유지. 누수·정답·평가 참가자·실행 경로 수정 후 성능을 다시 검증해야 합니다.** 이번 검토에서는 저장 출력을 읽었으며 모델을 재학습하지 않았습니다.

| 단계 | 노트북 | 역할 |
|---|---|---|
| 01 | [자료 준비와 EDA](notebooks/01_F1_Data_Prep_and_EDA.ipynb) | 원본 표 조인, 정답 생성, 탐색 |
| 02 | [변수 생성](notebooks/02_F1_Season_Feature_Engineering.ipynb) | 선수 누적·최근 성적과 팀 변수 |
| 03 | [모델링](notebooks/03_F1_Win_Modeling_Modern_Era.ipynb) | 로지스틱 회귀·랜덤 포레스트·후반 Top-10 모델 비교·SHAP |

저장 변수는 2016–2025년 4,300행입니다. 첫 학습/검증 분리는 2016–2023년 학습, 2024년 검증입니다. 연도 분리만으로 누수와 표본 편향이 없어지는 것은 아닙니다.

## 수정해야 할 내용

- 팀·경기 행이 아닌 드라이버 행을 이동해 같은 경기 팀 동료 결과가 경기 전 변수로 들어갑니다.
- 뒤처진 완주 기록을 DNF로 처리해 순위를 지웁니다. 원본에 맞는 완주·신뢰성 정답을 다시 구성해야 합니다.
- 우승·후반 Top-10 평가가 경기 후 순위 결측을 기준으로 참가자를 제외합니다. 경기 전 참가자 집합을 먼저 정의해야 합니다.
- 고정 로컬 경로와 유효하지 않은 일반 설치 셀을 수정하고 깨끗한 환경에서 전체 실행해야 합니다.
- 경기별 우승자 순위 평가·참가자 범위·단순 기준 모델·확률 보정을 검증하세요. SHAP은 모델 설명이며 인과 증거가 아닙니다.

[전체 검토와 유지·삭제 판단](../f1/baku-2026/docs/existing_f1_review.ko.md). 기존 코드·자료·모델은 변경하지 않았습니다. 현재 재검증된 성능 수치를 주장하지 않습니다.
